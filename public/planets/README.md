# Planet maps

Equirectangular maps and shaded disks used by FutureLife.

- Earth: NASA Visible Earth (Blue Marble / land_shallow_topo).
- Mercury, Venus, Moon, Mars, Jupiter, Saturn, Uranus, Neptune, Sun: NASA / USGS / JPL mosaics (MESSENGER, Magellan, LRO, Viking, Cassini, Voyager) via public-domain and NASA-derived 1k maps.
- Not NASA-official 8k products; colors match spacecraft true-color campaigns.

NASA media is generally public domain. Credit: NASA / JPL-Caltech / USGS / JHU-APL.
